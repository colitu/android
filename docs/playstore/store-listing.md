## English

**Name:** Colitu VPN

**Short description:** Fast, encrypted VPN with an account-based, no-logs design.

**Full description:**

Colitu sends your device's traffic through an encrypted tunnel to the Colitu server you choose.

• Connect with one tap. Adaptive Connect picks the best server and protocol for the network you are on.
• Split tunnelling: choose which apps use the VPN.
• Works with Android's always-on VPN.
• Optional ad-blocking DNS.
• The sites you visit are never recorded. Anonymous statistics can be turned off in settings.
• See and remove your devices in the app. Approve a TV sign-in with a QR code.
• Open source (GPL-3.0): github.com/colitu/android

A Colitu account is required. You can create one in the app.
Privacy: colitu.com/legal/privacy · Support: support@colitu.com

## Русский

**Название:** Colitu VPN

**Краткое описание:** Быстрый зашифрованный VPN без логов, с входом по аккаунту.

**Полное описание:**

Colitu передаёт трафик устройства по зашифрованному туннелю на выбранный вами сервер Colitu.

• Подключение одним нажатием. Adaptive Connect выбирает лучший сервер и протокол для вашей сети.
• Раздельное туннелирование: вы выбираете, какие приложения идут через VPN.
• Работает с функцией Android «Постоянная VPN».
• DNS с блокировкой рекламы (по желанию).
• Посещённые сайты не записываются. Анонимную статистику можно отключить в настройках.
• Ваши устройства видны в приложении, их можно удалить. Вход на ТВ подтверждается QR-кодом.
• Открытый исходный код (GPL-3.0): github.com/colitu/android

Нужен аккаунт Colitu. Его можно создать в приложении.
Конфиденциальность: colitu.com/legal/privacy · Поддержка: support@colitu.com
